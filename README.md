# IPL-ANALYSIS-DASHBOARD
🏏 IPL Analysis Dashboard | Power BI
📊 Project Overview

This project is an interactive IPL Analysis Dashboard created using Microsoft Power BI to analyze Indian Premier League data from 2008 to 2025.

The dashboard provides insights into team performance, player statistics, season-wise results, points tables, and important batting and bowling achievements.

🎯 Objectives
Analyze IPL performance across different seasons.
Compare team performance and points.
Identify season champions and runners-up.
Analyze Orange Cap and Purple Cap statistics.
Track total matches, teams, venues, fours, sixes, half-centuries, and centuries.
Provide an interactive dashboard using season selection.
📌 Key Dashboard Features
Season Selection: Filter the dashboard by IPL season.
Champion & Runner-up: Displays the winner and runner-up for the selected season.
KPI Cards: Shows:
Total Matches
Total Teams
Total Venues
Total Fours
Total Sixes
Half-Centuries
Centuries
Orange Cap Analysis: Displays the leading run scorer and total runs.
Purple Cap Analysis: Displays the leading wicket-taker and total wickets.
Top 4s & 6s: Highlights players with the most fours and sixes.
Points Table: Displays matches played, wins, losses, no-results, ties, and total points for each team.
